# Synthea synthetic population

This directory contains a reproducible synthetic patient population generated by
MITRE Synthea on 2026-11-21 using seed `20261121` and 1,000 patients.

- Source: <https://github.com/synthetichealth/synthea>
- License: Apache-2.0 for the Synthea generator
- Records are fictional and not patients.
- The generator models a Massachusetts/US-style population by default.
- These records are not validated Indian clinical data.
- They must not be used to claim real-world diagnostic accuracy.
- Patient names, addresses, and identifier fields in the CSV files are simulated.
- Keep this data for application testing and educational benchmarks only.

Generate the benchmark with:

```powershell
python -m backend.train_synthea
```
